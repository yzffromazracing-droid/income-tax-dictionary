# 税率

国税庁タックスアンサーをもとに、所得税の税率を整理したもの。

## 所得税の税率（速算表）

総合課税の所得や退職所得・山林所得にかかる所得税の税率は、5%から45%の7段階です。課税される所得金額（1,000円未満切捨て）×税率－控除額で求めます。

| 課税される所得金額 | 税率 | 控除額 | 出典 |
|---|---|---|---|
| 1,000円から1,949,000円まで | 5% | 0円 | [No.2260](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm) |
| 1,950,000円から3,299,000円まで | 10% | 97,500円 | [No.2260](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm) |
| 3,300,000円から6,949,000円まで | 20% | 427,500円 | [No.2260](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm) |
| 6,950,000円から8,999,000円まで | 23% | 636,000円 | [No.2260](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm) |
| 9,000,000円から17,999,000円まで | 33% | 1,536,000円 | [No.2260](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm) |
| 18,000,000円から39,999,000円まで | 40% | 2,796,000円 | [No.2260](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm) |
| 40,000,000円以上 | 45% | 4,796,000円 | [No.2260](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm) |

- 例：課税される所得金額が700万円なら 7,000,000円×23%－636,000円＝974,000円（[No.2260](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm)）
- 基準所得金額が3億3,000万円を超える場合は、超える部分の22.5%相当額が通常の税額を上回る部分が加算されます（特定の基準所得金額の課税の特例）（[No.2270](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2270.htm)）

## 復興特別所得税・防衛特別所得税

所得税と併せて、基準所得税額に一定の税率を掛けた復興特別所得税（令和9年分以後は防衛特別所得税も）を申告・納付します。源泉徴収の税率（15.315%・20.42%など）はこれを含んだものです。

| 区分 | 税率 | 内容 | 出典 |
|---|---|---|---|
| 復興特別所得税（令和8年分まで） | 2.1% | 基準所得税額に掛ける | [No.1522](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1522.htm) |
| 復興特別所得税（令和9年分以後） | 1.1% | 基準所得税額に掛ける | [No.1522](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1522.htm) |
| 防衛特別所得税（令和9年分以後） | 1% | 基準所得税額に掛ける | [No.1522](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1522.htm) |
| 源泉徴収の合計税率 | 変更なし | 令和9年以後も防衛特別所得税と復興特別所得税の合計税率は同じ | [No.1420](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1420.htm) |


## 分離課税の税率

他の所得と合計せずに税額を計算する所得の税率です。源泉分離課税は源泉徴収だけで課税が終わり、申告分離課税は確定申告で税額を計算します。

| 所得 | 税率 | 課税方法など | 出典 |
|---|---|---|---|
| 預貯金・一般公社債等の利子 | 15.315%（他に地方税5%） | 源泉分離課税 | [No.1310](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1310.htm) |
| 特定公社債等の利子 | 15.315%（他に地方税5%） | 申告分離課税（確定申告しないことも選択できる） | [No.1310](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1310.htm) |
| 上場株式等の配当等（申告分離課税を選択） | 15.315%（他に地方税5%） | 申告分離課税 | [No.1331](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1331.htm) |
| 株式等の譲渡所得等 | 所得税15%（住民税5%） | 申告分離課税。別に復興特別所得税 | [No.1463](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1463.htm) |
| 土地建物等の譲渡（長期：所有期間5年超） | 所得税15% | 申告分離課税。別に復興特別所得税 | [No.1440](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1440.htm) |
| 土地建物等の譲渡（短期：所有期間5年以下） | 所得税30% | 申告分離課税。別に復興特別所得税 | [No.1440](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1440.htm) |
| 先物取引に係る雑所得等（FXを含む） | 所得税15%（他に地方税5%） | 申告分離課税。別に復興特別所得税 | [No.1522](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1522.htm) |
| 金融類似商品の収益（定期積金の給付補てん金など） | 15.315%（他に地方税5%） | 源泉分離課税 | [No.1520](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1520.htm) |
| 一時払養老保険の差益など（保険期間5年以内など） | 15.315%（他に地方税5%） | 源泉分離課税（確定申告できない） | [No.1490](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1490.htm) |
| 退職所得 | 速算表の税率 | 他の所得と分離して計算 | [No.1420](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1420.htm) |
| 山林所得 | 速算表の税率（5分5乗方式） | （課税山林所得金額×5分の1×税率）×5 | [No.1480](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1480.htm) |

- 長期・短期は、譲渡した年の1月1日現在の所有期間が5年を超えるかどうかで分けます（[No.1440](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1440.htm)）

## 源泉徴収の税率

支払の際に源泉徴収される所得税および復興特別所得税の主な税率です（令和9年以後も合計税率は同じ）。

| 支払うもの | 税率 | 備考 | 出典 |
|---|---|---|---|
| 給与・賞与 | 源泉徴収税額表による | 月額表・日額表・賞与の算出率の表（辞書タブの年末調整 → 源泉徴収税額表） | [No.2511](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2511.htm) |
| 退職手当等（「退職所得の受給に関する申告書」を提出していない人） | 20.42% | 確定申告で精算 | [No.1420](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1420.htm) |
| 上場株式等の配当等（大口株主等を除く） | 15.315%（他に地方税5%） |  | [No.1330](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1330.htm) |
| 上場株式等以外の配当等 | 20.42%（地方税なし） |  | [No.1330](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1330.htm) |
| 原稿料・講演料、弁護士・税理士等の報酬など（100万円以下の部分） | 10.21% | 支払金額×10.21% | [No.2795](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2795.htm) |
| 原稿料・講演料、弁護士・税理士等の報酬など（100万円を超える部分） | 20.42% | （支払金額－100万円）×20.42%＋102,100円 | [No.2795](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2795.htm) |
| 非居住者への給与・報酬・退職手当等 | 20.42% |  | [No.2884](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2884.htm) |
| 非居住者への不動産の賃貸料等 | 20.42% |  | [No.2884](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2884.htm) |
| 非居住者からの土地等の譲受け（譲渡対価） | 10.21% |  | [No.2884](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2884.htm) |
| 非居住者への利子等 | 15.315% |  | [No.2884](https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2884.htm) |

- 令和9年1月1日以後に生ずる所得は、復興特別所得税1.1%と防衛特別所得税1%に分かれて源泉徴収されます（[No.1330](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1330.htm)）
